📖 Introduction & How to Use
A cheat-sheet reference for common DSA patterns. When you see a problem, find the pattern — don't reinvent the syntax.

🧭 How to identify the right topic

  • Contiguous subarray / sliding window → Arrays
  • Count/lookup in O(1) → Hashing
  • Detect cycle, reverse, merge → Linked Lists
  • Matching brackets, next greater → Stacks
  • BFS shortest path, levels → Graphs / Trees
  • K-th largest/smallest → Heap
  • Sorted array + find/count → Binary Search
  • All combos / subsets → Backtracking
  • Overlapping subproblems → DP
  • Local optimal = global optimal → Greedy

📦 Arrays & Strings
Most problems use a pointer/window technique. Master these patterns and 80% of array problems become formulaic.
Two Pointers Sliding Window Prefix Sum Kadane's

↔️ Two Pointers

Use when: sorted array, find pair/triplet, palindrome, container with water.
Template
def two_pointers(arr):
    l, r = 0, len(arr) - 1
    while l < r:
        curr = arr[l] + arr[r]
        if curr == target:
            return [l, r]
        elif curr < target:
            l += 1
        else:
            r -= 1

🪟 Sliding Window (Fixed Size)

Use when: find max/min of subarray of size k.
Template
def fixed_window(arr, k):
    window_sum = sum(arr[:k])
    best = window_sum
    for i in range(k, len(arr)):
        window_sum += arr[i] - arr[i - k]
        best = max(best, window_sum)
    return best

🪟 Sliding Window (Variable Size)

Use when: longest/shortest subarray satisfying a condition.
Template
def variable_window(arr):
    l = 0
    best = 0
    curr = 0         # window state
    for r in range(len(arr)):
        curr += arr[r]          # expand
        while curr > limit:   # shrink condition
            curr -= arr[l]
            l += 1
        best = max(best, r - l + 1)
    return best

➕ Prefix Sum

Use when: range sum queries, subarray sum equals k.
Template
# Build
prefix = [0] * (len(arr) + 1)
for i, v in enumerate(arr):
    prefix[i+1] = prefix[i] + v

# Sum of arr[l..r] inclusive:
range_sum = prefix[r+1] - prefix[l]

# Subarray sum == k (hashmap trick):
seen = {0: 1}; running = count = 0
for x in arr:
    running += x
    count += seen.get(running - k, 0)
    seen[running] = seen.get(running, 0) + 1

📈 Kadane's Algorithm (Max Subarray)

O(n) time
def max_subarray(nums):
    curr = best = nums[0]
    for n in nums[1:]:
        curr = max(n, curr + n)
        best = max(best, curr)
    return best

🔑 Key Reminders

  • Sliding window only works if the "value" is monotone as window grows
  • Two pointers need a sorted array (or sort first)
  • Prefix sum needs O(n) space — worth it for repeated queries
  • arr[i:j] in Python is O(j-i) — avoid inside hot loops
  • Use ord(c) - ord('a') to map chars to indices

# Two Sum pattern
def two_sum(nums, target):
    seen = {}
    for i, n in enumerate(nums):
        if target - n in seen:
            return [seen[target - n], i]
        seen[n] = i

🔑 Key Reminders

  • Lists/dicts are NOT hashable — use tuple() as key
  • frozenset() is hashable
  • Counter subtraction clips to 0 (no negatives)
  • Two Sum variant: complement = target - x
  • Detect duplicate in O(n): add to set, check len
  • Longest consecutive: put all in set, walk only from sequence start
Longest Consecutive Sequence — O(n)
def longest_consecutive(nums):
    s = set(nums)
    best = 0
    for n in s:
        if n - 1 not in s:   # start of sequence
            length = 1
            while n + length in s:
                length += 1
            best = max(best, length)
    return best
🔗 Linked Lists
Almost every linked list problem is solved with: fast/slow pointers, dummy head, or reversing in place.
Fast/Slow PointersDummy HeadReverseMerge

🏗️ Node Definition

class ListNode:
    def __init__(self, val=0, next=None):
        self.val = val
        self.next = next

# Build from list
def build(vals):
    dummy = ListNode(0)
    cur = dummy
    for v in vals:
        cur.next = ListNode(v); cur = cur.next
    return dummy.next

🐇🐢 Fast & Slow (Floyd's)

Detect cycle, find middle, find cycle start.
# Detect cycle
slow = fast = head
while fast and fast.next:
    slow = slow.next
    fast = fast.next.next
    if slow == fast: return True

# Find middle
slow = fast = head
while fast and fast.next:
    slow = slow.next
    fast = fast.next.next
# slow is now at middle

🔄 Reverse Linked List

# Iterative — O(n) time, O(1) space
def reverse(head):
    prev = None
    curr = head
    while curr:
        nxt = curr.next
        curr.next = prev
        prev = curr
        curr = nxt
    return prev

# Recursive
def reverse_rec(head):
    if not head or not head.next: return head
    new_head = reverse_rec(head.next)
    head.next.next = head
    head.next = None
    return new_head

🤝 Merge Two Sorted Lists

def merge(l1, l2):
    dummy = ListNode(0)
    cur = dummy
    while l1 and l2:
        if l1.val <= l2.val:
            cur.next = l1; l1 = l1.next
        else:
            cur.next = l2; l2 = l2.next
        cur = cur.next
    cur.next = l1 or l2
    return dummy.next

🔑 Key Reminders

  • Always use a dummy head when inserting/deleting — avoids edge case on head
  • To delete node at position k from end: fast pointer moves k steps first
  • Never lose your .next pointer before reassigning
  • Draw the arrows on paper before coding reversals
  • Cycle start: reset slow to head after meeting, move both 1 step

🗑️ Remove Nth from End

def remove_nth(head, n):
    dummy = ListNode(0, head)
    fast = slow = dummy
    for _ in range(n + 1):
        fast = fast.next
    while fast:
        fast = fast.next
        slow = slow.next
    slow.next = slow.next.next
    return dummy.next
📚 Stacks & Queues
Stack = LIFO. Queue = FIFO. Monotonic stack is the key unlock for "next greater element" class problems.

🔤 Valid Parentheses

def is_valid(s):
    stack = []
    match = {')':'(', '}':'{', ']':'['}
    for c in s:
        if c in match:
            if not stack or stack[-1] != match[c]:
                return False
            stack.pop()
        else:
            stack.append(c)
    return not stack

📉 Monotonic Stack (Next Greater)

Decreasing stack → next greater. Increasing stack → next smaller.
def next_greater(nums):
    n = len(nums)
    res = [-1] * n
    stack = []   # indices
    for i in range(n):
        while stack and nums[stack[-1]] < nums[i]:
            res[stack.pop()] = nums[i]
        stack.append(i)
    return res

🌊 Largest Rectangle in Histogram

def largest_rect(heights):
    stack = []   # (index, height)
    max_area = 0
    for i, h in enumerate(heights):
        start = i
        while stack and stack[-1][1] > h:
            idx, ht = stack.pop()
            max_area = max(max_area, ht * (i - idx))
            start = idx
        stack.append((start, h))
    for i, h in stack:
        max_area = max(max_area, h * (len(heights) - i))
    return max_area

🔑 Key Reminders

  • Use stack for anything "track previous state and compare"
  • Monotonic stack: maintain sorted order of stack at all times
  • BFS always uses a queue (deque) — never recursion
  • Daily Temperatures, Next Greater, Trapping Rain Water → Monotonic Stack
  • Min stack: keep a parallel stack of minimums

🌿 Tree DFS Traversals

# Inorder: Left → Root → Right (sorted for BST)
def inorder(root):
    if not root: return
    inorder(root.left)
    visit(root)
    inorder(root.right)

# Preorder: Root → Left → Right (serialize)
# Postorder: Left → Right → Root (delete, height)

# Generic DFS template
def dfs(node):
    if not node: return 0   # base case
    left  = dfs(node.left)
    right = dfs(node.right)
    return 1 + max(left, right)  # combine

🌊 BFS (Level Order)

from collections import deque

def bfs(root):
    if not root: return []
    q = deque([root])
    result = []
    while q:
        level = []
        for _ in range(len(q)):   # process level
            node = q.popleft()
            level.append(node.val)
            if node.left:  q.append(node.left)
            if node.right: q.append(node.right)
        result.append(level)
    return result

🗺️ Graph DFS / BFS

# DFS iterative
def dfs_graph(graph, start):
    visited = set([start])
    stack = [start]
    while stack:
        node = stack.pop()
        for nei in graph[node]:
            if nei not in visited:
                visited.add(nei)
                stack.append(nei)

# BFS shortest path
def bfs_graph(graph, start):
    visited = set([start])
    q = deque([start])
    dist = 0
    while q:
        for _ in range(len(q)):
            node = q.popleft()
            for nei in graph[node]:
                if nei not in visited:
                    visited.add(nei); q.append(nei)
        dist += 1

🔗 Union Find (Disjoint Set)

class UnionFind:
    def __init__(self, n):
        self.parent = list(range(n))
        self.rank = [0] * n

    def find(self, x):
        if self.parent[x] != x:
            self.parent[x] = self.find(self.parent[x])
        return self.parent[x]

    def union(self, x, y):
        px, py = self.find(x), self.find(y)
        if px == py: return False
        if self.rank[px] < self.rank[py]: px, py = py, px
        self.parent[py] = px
        if self.rank[px] == self.rank[py]: self.rank[px] += 1
        return True

🔢 Topological Sort (Kahn's BFS)

def topo_sort(n, edges):
    graph = defaultdict(list)
    indegree = [0] * n
    for u, v in edges:
        graph[u].append(v)
        indegree[v] += 1
    q = deque(i for i in range(n) if indegree[i] == 0)
    order = []
    while q:
        node = q.popleft(); order.append(node)
        for nei in graph[node]:
            indegree[nei] -= 1
            if indegree[nei] == 0: q.append(nei)
    return order if len(order) == n else []  # [] = cycle
⚠️ Always mark nodes visited BEFORE pushing to queue/stack (not after) to avoid duplicate processing in graphs with cycles.

🔑 BST Properties

  • Inorder traversal gives sorted array
  • Search: O(log n) average, O(n) worst
  • Validate: pass min/max bounds down recursively
  • LCA: if both nodes are left → go left; both right → go right; else current = LCA

🔑 Key Reminders

  • DFS → recursion or stack; BFS → always a queue
  • For grids: 4-directional = [(0,1),(0,-1),(1,0),(-1,0)]
  • Number of islands: DFS/BFS flood fill from each unvisited '1'
  • Detect cycle in directed graph: color (white/gray/black) or DFS with recursion stack
⛰️ Heaps (Priority Queue)
Python's heapq is a min-heap. Negate values for max-heap. Use when you need the k-th largest/smallest or always want the minimum next.

📋 heapq Syntax

import heapq

heap = []
heapq.heappush(heap, val)    # O(log n)
heapq.heappop(heap)          # O(log n) — smallest
heap[0]                       # peek min — O(1)
heapq.heapify(list)          # O(n) in-place
heapq.nlargest(k, iterable)  # O(n log k)
heapq.nsmallest(k, iterable)

# Max-heap: negate the value
heapq.heappush(heap, -val)
max_val = -heapq.heappop(heap)

# Tuple: (priority, data)
heapq.heappush(heap, (freq, word))

🏆 K-th Largest / Top K

# K-th largest — min-heap of size k
def kth_largest(nums, k):
    heap = nums[:k]
    heapq.heapify(heap)
    for n in nums[k:]:
        if n > heap[0]:
            heapq.heapreplace(heap, n)
    return heap[0]

# Top K frequent elements
def top_k_frequent(nums, k):
    freq = Counter(nums)
    return heapq.nlargest(k, freq, key=freq.get)

🔗 Merge K Sorted Lists

def merge_k(lists):
    heap = []
    for i, node in enumerate(lists):
        if node:
            heapq.heappush(heap, (node.val, i, node))
    dummy = cur = ListNode(0)
    while heap:
        val, i, node = heapq.heappop(heap)
        cur.next = node; cur = cur.next
        if node.next:
            heapq.heappush(heap, (node.next.val, i, node.next))
    return dummy.next

🔑 Key Reminders

  • Python heapq is MIN-heap only — negate for max behavior
  • For tuples: heap compares element by element (val, tiebreak, data)
  • Median of stream: two heaps (max-heap left half, min-heap right half)
  • heapq.heapreplace() is faster than pop + push
  • Use heap when you need "always the smallest/largest next element"
Median from Data Stream (Two Heaps)
class MedianFinder:
    def __init__(self):
        self.lo = []  # max-heap (negated) — left half
        self.hi = []  # min-heap — right half

    def addNum(self, num):
        heapq.heappush(self.lo, -num)
        heapq.heappush(self.hi, -heapq.heappop(self.lo))
        if len(self.hi) > len(self.lo):
            heapq.heappush(self.lo, -heapq.heappop(self.hi))

    def findMedian(self):
        if len(self.lo) == len(self.hi):
            return (-self.lo[0] + self.hi[0]) / 2
        return -self.lo[0]
💰 Greedy
Make the locally optimal choice at each step. Greedy works when a global optimum can be built from local optima — often hard to prove but common in interview problems.
IntervalsSchedulingJump GameGas Station

📅 Interval Scheduling

Sort by end time → always pick the interval that finishes earliest.
# Max non-overlapping intervals
def erase_overlapping(intervals):
    intervals.sort(key=lambda x: x[1])
    count = 0; end = float('-inf')
    for s, e in intervals:
        if s >= end:
            end = e
        else:
            count += 1  # remove this one
    return count

# Merge overlapping intervals
def merge(intervals):
    intervals.sort()
    merged = [intervals[0]]
    for s, e in intervals[1:]:
        if s <= merged[-1][1]:
            merged[-1][1] = max(merged[-1][1], e)
        else:
            merged.append([s, e])
    return merged

🏃 Jump Game

# Can reach end?
def can_jump(nums):
    reach = 0
    for i, n in enumerate(nums):
        if i > reach: return False
        reach = max(reach, i + n)
    return True

# Min jumps to reach end
def min_jumps(nums):
    jumps = cur_end = cur_far = 0
    for i in range(len(nums) - 1):
        cur_far = max(cur_far, i + nums[i])
        if i == cur_end:
            jumps += 1
            cur_end = cur_far
    return jumps

⛽ Gas Station

def can_complete_circuit(gas, cost):
    if sum(gas) < sum(cost): return -1
    tank = start = 0
    for i in range(len(gas)):
        tank += gas[i] - cost[i]
        if tank < 0:
            start = i + 1
            tank = 0
    return start

🔑 Key Reminders

  • Greedy needs a proof — ask "does local optimal guarantee global optimal?"
  • Interval problems: sort by START for merging, by END for scheduling
  • Greedy often pairs with sorting first
  • Two-pass greedy (left→right then right→left) solves many array problems
  • Candy, Trapping Rain Water: compute left/right arrays separately
🎯 Binary Search
Not just for sorted arrays. If the search space is monotone (a condition flips from False→True), binary search applies.
lo/hi pointersSearch on AnswerRotated Array

📋 Classic Template

def binary_search(arr, target):
    lo, hi = 0, len(arr) - 1
    while lo <= hi:
        mid = lo + (hi - lo) // 2   # no overflow
        if arr[mid] == target:
            return mid
        elif arr[mid] < target:
            lo = mid + 1
        else:
            hi = mid - 1
    return -1    # not found

⬅️ Find Leftmost / Lower Bound

# First position where arr[mid] >= target
def lower_bound(arr, target):
    lo, hi = 0, len(arr)
    while lo < hi:
        mid = (lo + hi) // 2
        if arr[mid] < target:
            lo = mid + 1
        else:
            hi = mid
    return lo   # insertion point

# Python built-in equivalents:
import bisect
bisect.bisect_left(arr, target)   # lower bound
bisect.bisect_right(arr, target)  # upper bound

🔍 Search on Answer

When asked "minimum X such that condition holds" → binary search on X.
# Template: minimize valid answer
lo, hi = min_possible, max_possible
while lo < hi:
    mid = (lo + hi) // 2
    if feasible(mid):
        hi = mid        # could do better
    else:
        lo = mid + 1   # need more
return lo

# feasible(mid) = can we do the task with value=mid?
# Examples: split array largest sum, koko eating bananas

🌀 Search Rotated Array

def search_rotated(nums, target):
    lo, hi = 0, len(nums) - 1
    while lo <= hi:
        mid = (lo + hi) // 2
        if nums[mid] == target: return mid
        # Left half sorted
        if nums[lo] <= nums[mid]:
            if nums[lo] <= target < nums[mid]:
                hi = mid - 1
            else: lo = mid + 1
        else:  # Right half sorted
            if nums[mid] < target <= nums[hi]:
                lo = mid + 1
            else: hi = mid - 1
    return -1

🔑 Key Reminders

  • Use lo + (hi - lo) // 2 to avoid overflow (less critical in Python)
  • lo < hi vs lo <= hi: use <= when returning on exact match, < for lower/upper bound
  • "Search on answer": set hi = max feasible answer, feasible() checks if mid works
  • Monotonic function + find threshold → binary search
  • bisect_left returns insert position if not found
↩️ Backtracking
Systematically explore all possibilities by building candidates and abandoning ("backtracking") when a candidate can't lead to a solution.
SubsetsPermutationsCombinationsN-Queens

🏗️ Universal Template

def backtrack(state, choices, result):
    if is_solution(state):
        result.append(state[:])    # snapshot copy!
        return
    for choice in choices:
        if is_valid(choice, state):
            state.append(choice)   # choose
            backtrack(state, next_choices, result)
            state.pop()            # un-choose

🗂️ Subsets (Power Set)

def subsets(nums):
    result = []
    def bt(start, curr):
        result.append(curr[:])
        for i in range(start, len(nums)):
            curr.append(nums[i])
            bt(i + 1, curr)
            curr.pop()
    bt(0, [])
    return result

# Subsets with duplicates: sort first, skip same element at same level
if i > start and nums[i] == nums[i-1]: continue

🔀 Permutations

def permute(nums):
    result = []
    def bt(curr, remaining):
        if not remaining:
            result.append(curr[:])
            return
        for i in range(len(remaining)):
            curr.append(remaining[i])
            bt(curr, remaining[:i] + remaining[i+1:])
            curr.pop()
    bt([], nums)
    return result

🎰 Combinations (k of n)

def combine(n, k):
    result = []
    def bt(start, curr):
        if len(curr) == k:
            result.append(curr[:])
            return
        for i in range(start, n + 1):
            curr.append(i)
            bt(i + 1, curr)
            curr.pop()
    bt(1, [])
    return result

# Pruning: stop early when not enough elements remain
if n - i + 1 < k - len(curr): break

🔢 Word Search / Grid Backtracking

def exist(board, word):
    rows, cols = len(board), len(board[0])
    def bt(r, c, idx):
        if idx == len(word): return True
        if r < 0 or r >= rows or c < 0 or c >= cols: return False
        if board[r][c] != word[idx]: return False
        tmp, board[r][c] = board[r][c], '#'  # mark visited
        found = any(bt(r+dr, c+dc, idx+1) for dr,dc in [(0,1),(0,-1),(1,0),(-1,0)])
        board[r][c] = tmp   # restore
        return found
    return any(bt(r, c, 0) for r in range(rows) for c in range(cols))

🔑 Key Reminders

  • Always copy state when adding to result: result.append(curr[:])
  • Avoid duplicates: sort + skip if i > start and nums[i] == nums[i-1]
  • Prune early to cut branches — crucial for performance
  • Time: O(2ⁿ) subsets, O(n!) permutations — only feasible for small n
  • Use a used boolean array for permutations with duplicates

📊 Bottom-Up (Tabulation)

# Coin Change — minimum coins
def coin_change(coins, amount):
    dp = [float('inf')] * (amount + 1)
    dp[0] = 0
    for a in range(1, amount + 1):
        for c in coins:
            if c <= a:
                dp[a] = min(dp[a], 1 + dp[a - c])
    return dp[amount] if dp[amount] != float('inf') else -1

🎒 0/1 Knapsack

# weights, values, capacity W
def knapsack(weights, values, W):
    n = len(weights)
    dp = [[0]*(W+1) for _ in range(n+1)]
    for i in range(1, n+1):
        for w in range(W+1):
            dp[i][w] = dp[i-1][w]   # skip item
            if weights[i-1] <= w:
                dp[i][w] = max(dp[i][w],
                    values[i-1] + dp[i-1][w-weights[i-1]])
    return dp[n][W]

📏 LCS / Edit Distance

# Longest Common Subsequence
def lcs(s, t):
    m, n = len(s), len(t)
    dp = [[0]*(n+1) for _ in range(m+1)]
    for i in range(1, m+1):
        for j in range(1, n+1):
            if s[i-1] == t[j-1]:
                dp[i][j] = dp[i-1][j-1] + 1
            else:
                dp[i][j] = max(dp[i-1][j], dp[i][j-1])
    return dp[m][n]

📈 LIS (Longest Increasing Subsequence)

# O(n log n) with patience sorting
def lis(nums):
    tails = []
    for n in nums:
        lo, hi = 0, len(tails)
        while lo < hi:
            mid = (lo + hi) // 2
            if tails[mid] < n: lo = mid + 1
            else: hi = mid
        if lo == len(tails): tails.append(n)
        else: tails[lo] = n
    return len(tails)

# O(n²) DP version:
# dp[i] = max LIS ending at i
# dp[i] = 1 + max(dp[j] for j < i if nums[j] < nums[i])

🔑 Key Reminders

  • Define state clearly: dp[i] = "answer for first i elements"
  • Recurrence = transition between states
  • Base case = smallest subproblem (dp[0] or dp[0][0])
  • @lru_cache makes top-down trivial in Python
  • Space optimize: if dp[i] only depends on dp[i-1], use 1D or two arrays
  • House robber: dp[i] = max(dp[i-1], dp[i-2] + nums[i])
  • Unique paths: dp[i][j] = dp[i-1][j] + dp[i][j-1]
Common DP recurrences to memorize
# Climbing stairs / Fibonacci-like
dp[i] = dp[i-1] + dp[i-2]

# House Robber (no adjacent)

# Partition equal subset sum (subset-sum variant)
dp[j] = dp[j] or dp[j - num]   # iterate j backwards

# Unique paths (grid, m x n)
dp[i][j] = dp[i-1][j] + dp[i][j-1]

# Word break
dp[i] = any(dp[j] and s[j:i] in word_set for j in range(i))

# Longest palindromic substring
dp[i][j] = dp[i+1][j-1] and s[i] == s[j]

💡 LRU Cache (Meta Classic)

class Node:
    def __init__(self, k, v):
        self.key=k; self.val=v
        self.prev=self.next=None

class LRUCache:
    def __init__(self, cap):
        self.cap=cap; self.cache={}
        self.head=Node(0,0); self.tail=Node(0,0)
        self.head.next=self.tail; self.tail.prev=self.head
    def _remove(self,n):
        n.prev.next=n.next; n.next.prev=n.prev
    def _insert(self,n):
        n.next=self.head.next; n.prev=self.head
        self.head.next.prev=n; self.head.next=n
    def get(self,k):
        if k not in self.cache: return -1
        self._remove(self.cache[k]); self._insert(self.cache[k])
        return self.cache[k].val
    def put(self,k,v):
        if k in self.cache: self._remove(self.cache[k])
        self.cache[k]=Node(k,v); self._insert(self.cache[k])
        if len(self.cache)>self.cap:
            lru=self.tail.prev; self._remove(lru); del self.cache[lru.key]
🔤 Trie (Prefix Tree)
A tree where each node is a character. Perfect for prefix lookups, autocomplete, and word search. Very common at Google and Meta.
Insert O(m)Search O(m)Prefix SearchWord Search II

🏗️ Trie Implementation

class TrieNode:
    def __init__(self):
        self.children = {}
        self.is_end = False

class Trie:
    def __init__(self):
        self.root = TrieNode()

    def insert(self, word):
        node = self.root
        for c in word:
            if c not in node.children:
                node.children[c] = TrieNode()
            node = node.children[c]
        node.is_end = True

    def search(self, word):
        node = self.root
        for c in word:
            if c not in node.children: return False
            node = node.children[c]
        return node.is_end

    def startsWith(self, prefix):
        node = self.root
        for c in prefix:
            if c not in node.children: return False
            node = node.children[c]
        return True

🃏 Word Search II (Trie + Backtracking)

Build Trie from word list, DFS the board matching against it.
def findWords(board, words):
    trie = Trie()
    for w in words: trie.insert(w)
    rows,cols=len(board),len(board[0])
    result=set()
    def dfs(r,c,node,path):
        if node.is_end: result.add(path)
        tmp,board[r][c]=board[r][c],'#'
        for dr,dc in [(0,1),(0,-1),(1,0),(-1,0)]:
            nr,nc=r+dr,c+dc
            if 0<=nr<rows and 0<=nc<cols:
                ch=board[nr][nc]
                if ch in node.children:
                    dfs(nr,nc,node.children[ch],path+ch)
        board[r][c]=tmp
    for r in range(rows):
        for c in range(cols):
            ch=board[r][c]
            if ch in trie.root.children:
                dfs(r,c,trie.root.children[ch],ch)
    return list(result)

🔍 Wildcard Search ('.' matches any)

def search_wildcard(self, word):
    def dfs(node, i):
        if i == len(word): return node.is_end
        c = word[i]
        if c == '.':
            return any(dfs(child, i+1)
                for child in node.children.values())
        if c not in node.children: return False
        return dfs(node.children[c], i+1)
    return dfs(self.root, 0)

  • Trie beats HashMap when you need prefix search, not just exact match

🔦 XOR Magic

XOR: same bits cancel. Pairs wipe out, leaving the unique element.
# Single Number — one appears once, rest twice
def single_number(nums):
    res = 0
    for n in nums: res ^= n
    return res   # O(n) time, O(1) space

# Missing number (0..n)
def missing(nums):
    res = len(nums)
    for i, n in enumerate(nums):
        res ^= i ^ n
    return res

🧮 Count Bits

# Hamming weight (count 1s in n)
def hamming_weight(n):
    count = 0
    while n:
        n &= n - 1   # clear lowest set bit
        count += 1
    return count

# Count bits 0..n (DP)
def count_bits(n):
    dp = [0] * (n + 1)
    for i in range(1, n+1):
        dp[i] = dp[i >> 1] + (i & 1)
    return dp

🔍 Common Tricks

# Is power of 2?
n > 0 and (n & n-1) == 0

# Get bit at position i
(n >> i) & 1

# Set bit at position i
n | (1 << i)

# Clear bit at position i
n & ~(1 << i)

# Toggle bit at position i
n ^ (1 << i)

# Reverse 32 bits
def reverse_bits(n):
    res = 0
    for _ in range(32):
        res = (res << 1) | (n & 1)
        n >>= 1
    return res

🔑 Key Reminders

  • XOR is commutative & associative — order doesn't matter
  • n & (n-1) removes lowest set bit — use for bit counting
  • n & (-n) isolates lowest set bit — use to split groups
  • Bitmask DP: represent subsets as integers (used in TSP, scheduling)
  • Python integers have no overflow — no 32-bit wrapping issues
  • Must-know: Single Number I/II/III, Missing Number, Reverse Bits, Sum Without +
🗺️ Graph Algorithms

⚡ Dijkstra (Weighted, No Negatives)

O((V+E) log V) with min-heap. Single source shortest path.
import heapq

def dijkstra(graph, src, n):
    # graph[u] = [(weight, v), ...]
    dist = [float('inf')] * n
    dist[src] = 0
    heap = [(0, src)]
    while heap:
        d, u = heapq.heappop(heap)
        if d > dist[u]: continue  # stale
        for w, v in graph[u]:
            nd = dist[u] + w
            if nd < dist[v]:
                dist[v] = nd
                heapq.heappush(heap, (nd, v))
    return dist

🔄 Bellman-Ford (Handles Negatives)

Detects negative cycles. O(V·E) — slower than Dijkstra.
def bellman_ford(n, edges, src):
    # edges = [(u, v, w)]
    dist = [float('inf')] * n
    dist[src] = 0
    for _ in range(n - 1):  # relax V-1 times
        for u, v, w in edges:
            if dist[u] + w < dist[v]:
                dist[v] = dist[u] + w
    for u, v, w in edges:    # detect neg cycle
        if dist[u] + w < dist[v]: return None
    return dist

🌐 Floyd-Warshall (All Pairs)

O(V³). Find shortest path between every pair. Small graphs only.
def floyd_warshall(dist):
    # dist[i][j] = edge weight (inf if none)
    n = len(dist)
    for k in range(n):
        for i in range(n):
            for j in range(n):
                dist[i][j] = min(dist[i][j],
                    dist[i][k] + dist[k][j])
    return dist

🌲 Kruskal's MST (Sort + Union-Find)

Sort edges by weight. Add if no cycle. O(E log E).
def kruskal(n, edges):
    # edges = [(w, u, v)]
    edges.sort()
    uf = UnionFind(n)
    total = 0
    for w, u, v in edges:
        if uf.union(u, v):
            total += w
    return total

🌿 Prim's MST (Heap)

Grow MST one vertex at a time. O(E log V).
def prim(graph, n):
    # graph[u] = [(w, v)]
    visited = set()
    heap = [(0, 0)]
    total = 0
    while heap and len(visited) < n:
        w, u = heapq.heappop(heap)
        if u in visited: continue
        visited.add(u); total += w
        for wt, v in graph[u]:
            if v not in visited:
                heapq.heappush(heap, (wt, v))
    return total if len(visited)==n else -1

def network_delay_time(times, n, k):
    graph = defaultdict(list)
    for u, v, w in times: graph[u].append((w, v))
    dist = {k: 0}; heap = [(0, k)]
    while heap:
        d, u = heapq.heappop(heap)
        if d > dist.get(u, float('inf')): continue
        for w, v in graph[u]:
            nd = d + w
            if nd < dist.get(v, float('inf')):
                dist[v] = nd; heapq.heappush(heap, (nd, v))
    return max(dist.values()) if len(dist)==n else -1
